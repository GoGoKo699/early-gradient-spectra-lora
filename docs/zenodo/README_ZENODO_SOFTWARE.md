Recommended contents:

```text

paper.pdf
SHA256SUMS.txt
README_ZENODO_SOFTWARE.md
LICENSE
CITATION.cff
THIRD_PARTY_NOTICES.md
```

Build the ZIP from the final `Publication/GitHub` tag, not from the
`Lora_Project` mother workspace.

```text
README.md
REPRODUCIBILITY.md
RELEASE_ARTIFACTS.json
CITATION.cff
ARTIFACT_LEDGER.md

```
