# Provenance documents

This directory records how the final publication-facing package was reconciled
from the author working environment.

The release itself is built from `Publication/GitHub` and the large data
companion is built from `Local`. The `Lora_Project` mother workspace is not
published wholesale because it contains historical manifests and working-tree
material. Selected documents from that workspace are copied here as provenance
records.

Files under `historical/` are retained for chronology and auditability. They are
not active release manifests unless a later document explicitly says otherwise.
